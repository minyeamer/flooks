# 대시보드에서 차트 편집

대시보드에서는 평소 차트 패널과 공통 필터만 보인다. 패널 본문을 클릭하거나 키보드로 선택하면 우측에 차트 편집기가 열린다. 작은 화면에서는 같은 편집기가 전체 화면 drawer로 열린다.

## 기본 흐름

1. 수정할 차트 패널을 선택한다.
2. 우측 편집기에서 차원, 지표, 표시 방식, 필터, 정렬을 바꾼다.
3. `미리보기`로 공통 대시보드 기간·필터를 적용한 결과를 확인한다.
4. `차트 저장`을 눌러 새 ChartAsset revision을 만든다.
5. 상단 `대시보드 저장`을 눌러 현재 패널이 새 revision을 사용하도록 저장한다.

`차트 저장`과 `대시보드 저장`은 의도적으로 다른 작업이다. 차트 저장만 하면 새 revision은 생성되지만 대시보드의 pinned revision은 서버에 아직 바뀌지 않는다. 대시보드의 `저장되지 않은 변경` 표시가 사라질 때까지 대시보드 저장을 완료해야 한다.

## 패널 작업

편집기 상단의 패널 작업으로 다음을 수행할 수 있다.

- `패널 새로고침`: 선택 패널만 원본 데이터로 다시 조회한다.
- `패널 복제`: 동일 차트와 revision을 새 위치의 패널로 추가한다.
- `패널 삭제`: 대시보드에서만 제거한다. 원본 ChartAsset은 삭제되지 않는다.

패널 제목의 revision 번호는 현재 대시보드가 pin한 ChartAsset revision이다. 최신 차트 revision이 존재하면 패널의 갱신 버튼으로 새 revision을 대시보드 draft에 반영할 수 있으며, 이후 대시보드 저장이 필요하다.

## JSON 고급 편집

우측 drawer의 JSON 고급 편집은 같은 ChartDocument draft를 편집한다. 일반적인 필드 선택과 JSON 편집 결과는 동일하게 저장된다. JSON 문법이 잘못됐거나 필터 값이 미완성인 상태에서는 미리보기와 저장을 할 수 없다.

## 주의 사항

- drawer를 닫을 때 저장하지 않은 차트 draft가 있으면 변경을 버릴지 확인한다.
- 다른 사용자가 먼저 같은 ChartAsset을 저장해 ETag 충돌이 발생하면 자동으로 덮어쓰지 않는다. 최신 revision을 확인한 뒤 다시 저장해야 한다.
- 대시보드 공통 필터는 현재 날짜·플랫폼·팀·브랜드 입력을 사용한다. Manifest 기반 선택 목록과 읽기 전용 공유 URL은 후속 기능이다.
