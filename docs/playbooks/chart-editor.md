# 차트 편집기 사용법

차트 편집기는 JSON을 직접 쓰지 않아도 ChartAsset을 만들고 수정할 수 있는 화면이다. 왼쪽 미리보기에서 결과를 확인하고, 오른쪽 설정 패널에서 데이터와 표시 방법을 조합한다. 저장 시 현재 설정은 하나의 immutable revision으로 남는다.

## 기본 흐름

1. 차트 라이브러리에서 차트를 선택하거나 새 차트를 만든다.
2. 제목, 차트 유형, 데이터셋과 조회 기간을 정한다.
3. 차원과 지표를 추가하거나 제거한다.
4. 필요하면 필터와 정렬을 추가한다.
5. `미리보기`로 실제 조회 결과를 확인한 뒤 `저장`한다.

지원하는 유형은 KPI, 라인, 막대, 표다. KPI는 하나의 지표만 표시한다. 라인과 막대는 보통 하나 이상의 차원과 지표가 필요하며, 막대는 누적 표시를 선택할 수 있다. 표는 페이지 크기를 설정할 수 있다.

### 표 열 너비와 고정

표 차트를 선택하면 `표 열` 설정이 나타난다. 기본인 `표 크기에 맞춤`은 모든 열을 표의 현재 폭에 맞춰 표시한다. 열마다 입력하는 숫자는 상대 비율이므로 `광고명: 3`, `광고비: 1`처럼 긴 텍스트 열에 더 큰 비율을 줄 수 있다. 창이나 대시보드 패널 크기가 변해도 전체 표 폭을 채운다.

`고정 너비와 가로 스크롤`을 선택하면 열 너비는 픽셀(px)이다. 이 모드에서는 왼쪽 고정 열 수를 정할 수 있고, 고정되지 않은 열은 표 바깥으로 넘쳐 가로 스크롤로 확인한다. 예를 들어 차원 열 두 개를 `2개`로 고정하고 광고비·전환액 열을 오른쪽에서 스크롤해 볼 수 있다.

이 값은 JSON의 `spec.visualization.table`에도 그대로 저장된다.

```json
"table": {
  "layout": "fixed",
  "frozenColumns": 2,
  "columnWidths": {"platform_name": 120, "campaign_name": 260, "ad_cost": 140}
}
```

## 데이터 필드

데이터셋은 서버가 제공하는 Dataset Manifest에서 온다. 차원은 날짜·플랫폼·브랜드처럼 데이터를 나누는 기준이고, 지표는 광고비·전환액·ROAS처럼 계산되는 값이다. 화면에서 보이지 않는 필드는 선택하거나 질의할 수 없다.

데이터셋을 바꾸면 기존 필드가 새 데이터셋에 없을 수 있으므로 차원, 지표, 필터, 정렬을 새 데이터셋의 기본값으로 다시 만든다. 기간은 유지한다.

## 필터와 정렬

`필터 추가`는 필드와 연산자를 한 줄씩 만든다.

- 같음(`eq`)과 포함(`contains`)은 한 값을 입력한다.
- 목록 중 하나(`in`)는 쉼표로 여러 값을 입력한다.
- 범위(`between`)는 시작과 끝을 모두 입력한다. 날짜 필드는 날짜 입력창을 사용한다.
- 비어 있음 여부(`isNull`)는 값이 비어 있는 행 또는 비어 있지 않은 행을 고른다.

필터 값이 덜 입력된 상태에서는 잘못된 조회를 막기 위해 미리보기와 저장을 할 수 없다. 정렬도 여러 줄을 추가할 수 있으며, 차원과 지표 중 하나를 기준으로 오름차순 또는 내림차순을 선택한다.

## JSON 고급 편집

`JSON 고급 편집`을 열면 같은 ChartDocument를 직접 볼 수 있다. JSON을 수정하면 설정 패널과 미리보기가 즉시 같은 문서를 사용한다. JSON 문법이 잘못된 동안에는 저장할 수 없다. JSON 가져오기와 내보내기는 이 문서를 파일로 주고받는 기능이다.

JSON은 표현력을 우회하는 수단이 아니다. API는 Dataset Manifest의 allowlist와 QuerySpec 규칙을 다시 검사하므로 raw SQL이나 임의 실행 코드는 사용할 수 없다.

## 현재 제한

- 필터 선택값을 데이터에서 자동 완성하는 기능은 아직 없다.
- 파이·도넛, 계산 필드, 복수 데이터셋 조인, 드래그로 차트를 직접 편집하는 기능은 아직 없다.
- 다른 사용자의 저장이 있으면 revision 알림과 비교를 통해 반영해야 하며, 자동 덮어쓰기는 하지 않는다.
